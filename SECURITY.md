# Security policy

## Supported versions

Only the latest release of Highrise gets fixes. Please update before reporting.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately instead:

1. Open the [Security tab](https://github.com/vectorviolet/highrise/security) of this repository.
2. Choose **Report a vulnerability** and describe what you found, how to reproduce it and what it
   could affect.

This is a small personal project, so replies are best effort, usually within a week. Once a fix is
released you are welcome to be credited in the release notes.
